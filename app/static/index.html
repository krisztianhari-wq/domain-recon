Ismert sebezhetőségek (CVE)

Az élő hostok fejlécéből termék+verzió → ismert kritikus CVE (verzió alapján, nem kihasználás).

Mit néz a vizsgálat?

A) Verzió alapján (Server / X-Powered-By fejléc):

  • PHP php2shell RCE — CVE-2026-109618 / CVE-2026-109619
  • PHP-CGI argumentuminjekció (RCE) — CVE-2024-4577 (Windows+CGI)
  • Apache path traversal → RCE — CVE-2021-41773 / CVE-2021-42013 (2.4.49/2.4.50)
  • Apache mod_proxy SSRF — CVE-2021-40438 (≤2.4.48)

B) Ujjlenyomat alapján (kíméletes GET):

  • Confluence OGNL-injekció (RCE) — CVE-2022-26134

Kitett eszközök (AI / low-code / monitoring)

Az élő hostokon kíméletes GET-ekkel: Flowise, Langflow, n8n, Open WebUI, Ollama, Grafana, Cacti… → termék + verzió + auth-állapot + ismert sebezhető verzió (nem kihasználás).

Mit néz a vizsgálat?

AI / low-code:

  • Ollama API — verzió, nyílt /api/tags (auth nélkül), Probllama RCE (CVE-2024-37032)
  • Open WebUI — verzió, nyitott regisztráció / kikapcsolt auth
  • Flowise — verzió, auth nélküli felület, auth-bypass (CVE-2024-31621)
  • Langflow — verzió, unauth RCE (CVE-2025-3248)
  • n8n — verzió, beállítatlan (nyitott owner-regisztráció)

Monitoring:

  • Grafana — verzió, path traversal (CVE-2021-43798)
  • Cacti — verzió, ismert RCE (< 1.2.27)
  • Zabbix, Netdata, Prometheus, Portainer — elérhetőség + verzió
